# HTML Portfolio — John Carreño

A multi-page personal portfolio website built with semantic HTML, CSS and vanilla JavaScript.

🌐 **Live site:** [john0487.github.io/html-portfolio](https://john0487.github.io/html-portfolio)

## Pages

- **Home** — Hero section, work experience, education and teacher reviews
- **Projects** — List of frontend projects
- **Articles** — Blog-style articles about frontend development
- **Contact** — Functional contact form powered by Web3Forms

## Features

- Semantic HTML5 structure across all pages
- SEO and Open Graph meta tags on every page
- 3-column layout on homepage using CSS Grid
- Responsive design for mobile and desktop
- Dark mode toggle on all pages
- Functional contact form with email delivery
- Active page indicator in the navbar using `aria-current`
- Favicon on all pages

## Technologies Used

- HTML5
- CSS3
- JavaScript (vanilla)
- Web3Forms (contact form)
- GitHub Pages (deployment)

## What I Learned

- How to structure a multi-page website with semantic HTML
- How to create complex layouts with CSS Grid and Flexbox
- How to write responsive CSS with media queries
- How to connect a static form to a backend service
- How to apply accessibility attributes like `aria-current`
- Version control with Git and GitHub

## Running Locally

```bash
git clone https://github.com/john0487/html-portfolio.git
cd html-portfolio
```

Then open `index.html` with Live Server in VS Code.
